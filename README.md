## Desciption Project

It's the educational project for my portfolio Junior DevOps Engineer.
The project demonstrates deploying a simple Nginx-app to Kubernetes using: 

- Docker (personal image Nginx)
- Kubernetes Deployment and Service
- Namespace for resource isolation
- NodePort for access to application
- Prepear to CI/CD and monitoring
